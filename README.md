# CaffeinGO ☕🌙

언제 카페인을 얼마나 먹었는지 입력하면, 최적의 취침시간과 기상시간, 총 수면시간을 알려주는 앱.

## 팀 세송이

건양대학교 의료IT공학과 팀 프로젝트 (2026.09.09–2026.12.08)

- 곽준성 26615002 · 배윤학 26615026 · 박현민 26615025

## 사용 방법

`index.html`을 브라우저로 열면 바로 쓸 수 있다. 서버도 설치도 필요 없다. 기록은 브라우저 localStorage에 저장된다.

GitHub Pages로 공개하면 웹에서 바로 열 수 있다. Settings → Pages → Branch `main`, 폴더 `/(root)`로 설정하면 된다.

## 기능

- **카페인 기록** — 아메리카노·라떼·콜드브루 등 프리셋 원탭 기록, 직접 입력, 기록 시간 수정
- **최적 수면 플랜** — 혈중 카페인 농도가 1.0mg/L 아래로 떨어지는 첫 시각이 최적 취침시간, +7시간 30분이 기상시간
- **상세 농도 곡선** — 24시간 농도 곡선을 좌우로 이동하며 확인. 곡선과 효과 종료 기준선(1.0mg/L)이 만나는 접점에 파란 취침 마커 표시
- **취침 시 예상** — 설정한 취침 시간의 예상 농도와 수면 판정
- **내 몸 기준 비교** — 같은 커피 한 잔(150mg, 16:00)도 내 몸이면 얼마나 다르게 남는지 평균 성인과 수치로 비교
- **대사 속도** — 빠름 3.5시간 / 보통 5시간 / 느림 7시간 반감기 선택 (CYP1A2 유전자에 따른 개인차 반영)
- **근거 섹션** — 카페인을 왜 조심해야 하는지 연구 근거와 함께 정리

## 계산 방법

- **체수분량** — Watson 공식 (키·몸무게·나이·성별)
- **흡수·감소** — 섭취 후 45분 선형 상승, 이후 반감기 지수 감쇠, 여러 잔 합산
- **효과 종료 기준선 1.0mg/L** — 연구의 직접 제시값이 아니라, 아래 연구들에 근거한 실용적 기준이다
- **최적 음용 시각** — 기상 후 90분 (코르티솔 각성 반응)
- **수면 시간** — 90분 × 5주기 = 7시간 30분

## 출처

- Drake et al. 2013, J Clin Sleep Med — 취침 6시간 전 카페인도 수면 40분 이상 단축
- Gardiner et al. 2023 (메타분석, 24개 연구) — 평균 수면 45분 단축, 커피 1잔은 취침 8.8시간 전 마감
- FDA·EFSA — 건강한 성인 하루 400mg, 1회 200mg
- Clow et al. 2004 — 코르티솔 각성 반응은 기상 후 30~45분 정점
- Cornelis et al. 2011, PLOS Genetics — CYP1A2 유전자와 카페인 대사 속도

이 앱은 건강 정보를 제공하지만 의료 진단이나 처방이 아니다.
